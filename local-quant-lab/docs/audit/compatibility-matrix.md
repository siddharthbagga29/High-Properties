## Why the current engine stays primary

The current engine covers what the research plan needs today: daily bars, next-open fills, explicit costs, the deterministic risk engine on every fill, preregistered walk-forward, a single-use holdout, the forward paper log, and now a Monte Carlo bootstrap. It is tested, has no dependencies and uses about 30 MB per process. NautilusTrader proved it can reproduce the same results when given open trades, so a later migration has a parity test to start from.
